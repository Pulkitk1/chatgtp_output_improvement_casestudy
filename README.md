#  ChatGPT Output Evaluation

A product case study exploring how ChatGPT can help users better evaluate AI-generated outputs instead of blindly trusting them.

## Problem

Students and early-career professionals frequently use ChatGPT for research, learning, writing, and decision-making. While answers are often well-written and convincing, users struggle to determine:

* What assumptions were made
* What information is missing
* What parts of the answer should be verified
* Whether the output is reliable enough to act on

This creates a gap between answer quality and user confidence.

## Research

The project combines:

* Secondary research on AI trust and confidence calibration
* User surveys and insight synthesis
* Competitor analysis of ChatGPT, Claude, Gemini, and Perplexity
* Persona development and problem validation

## Solution

### Review Mode (Selected Solution)

A post-response review layer that appears after ChatGPT generates an answer.

It helps users evaluate outputs through:

* **Assumptions** – What ChatGPT assumed while generating the answer
* **Missing Information** – Important context not provided by the user
* **Areas to Verify** – Claims and details that should be checked before action

The goal is not to replace user judgment, but to support more informed and calibrated decision-making.
